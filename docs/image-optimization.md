# Image Optimization Guide

This document describes the WebP image optimization setup for the IGRS2nd project, including the conversion process, results, and how the optimized images are served.

## Overview

All rating and descriptor PNG images have been converted to WebP format using [sharp](https://sharp.pixelplumbing.com/). The WebP files are served alongside the original PNGs via the HTML `<picture>` element, providing automatic format negotiation with zero JavaScript overhead.

## Conversion Script

The conversion script lives at `ops/scripts/convert-webp.js` and uses `sharp` (installed as a dev dependency).

### Running the Conversion

```bash
node ops/scripts/convert-webp.js
```

The script will:
1. Scan `public/assets/data/images/ratings/` and `public/assets/data/images/descriptors/` for PNG files
2. Convert each PNG to WebP with quality 80 and effort 6
3. Place the `.webp` file alongside the original `.png` in the same directory
4. Log each conversion with before/after sizes and percentage savings

### Configuration

The script uses these sharp WebP options:

```javascript
{ quality: 80, effort: 6 }
```

- **quality: 80** — Good balance between file size and visual fidelity for these icon-style images
- **effort: 6** — Maximum compression effort (0–6 scale); slower conversion but smaller output

### When to Re-run

Run the script whenever new PNG images are added to the ratings or descriptors directories. The script is idempotent — it will overwrite existing WebP files.

## How `<picture>` Element Serving Works

The codebase uses the HTML `<picture>` element to serve WebP with PNG fallback. This is a native browser feature requiring no JavaScript.

### Pattern

```tsx
<picture>
  <source srcSet={`/assets/data/images/ratings/${id}.webp`} type="image/webp" />
  <img src={`/assets/data/images/ratings/${id}.png`} alt="..." loading="lazy" />
</picture>
```

### How It Works

1. The browser evaluates `<source>` elements in order
2. If the browser supports `image/webp`, it loads the WebP file from `srcSet`
3. If no `<source>` matches, the browser falls back to the `<img>` element (PNG)
4. The `loading="lazy"` attribute defers loading until the image is near the viewport

### Components Using This Pattern

| Component | Location | Images |
|-----------|----------|--------|
| `RatingBadge` | `src/shared/components/rating-badge.tsx` | Rating icons |
| `DescriptorIcons` | `src/shared/components/descriptor-icons.tsx` | Descriptor icons |
| `RatingsPage` | `src/features/ratings/ratings-page.tsx` | Rating & descriptor guide cards |
| `HomePage` | `src/features/home/home-page.tsx` | Rating icons in overview |

### Path Helpers

WebP and PNG paths are generated by helper functions in `src/shared/lib/ratings.ts`:

```typescript
const IMAGE_BASE = '/assets/data/images';

export const IMG_RATING = (id: number): string => `${IMAGE_BASE}/ratings/${id}.png`;
export const IMG_RATING_WEBP = (id: number): string => `${IMAGE_BASE}/ratings/${id}.webp`;

export const IMG_DESCRIPTOR_WEBP = (id: number): string => `${IMAGE_BASE}/descriptors/cc-${id}.webp`;
```

## Alternative Tools

If `sharp` cannot be installed (e.g., native dependency issues on certain platforms), these alternatives can produce equivalent WebP output:

### Google cwebp (CLI)

Part of the [libwebp](https://developers.google.com/speed/webp/docs/cwebp) package.

```bash
# Install (macOS)
brew install webp

# Install (Ubuntu/Debian)
sudo apt install webp

# Convert a single file
cwebp -q 80 input.png -o output.webp

# Batch convert all PNGs in a directory
for f in public/assets/data/images/ratings/*.png; do
  cwebp -q 80 "$f" -o "${f%.png}.webp"
done
```

### Squoosh CLI

Google's [Squoosh CLI](https://github.com/GoogleChromeLabs/squoosh/tree/dev/cli) — no native dependencies, runs in Node.js via WASM.

```bash
npx @squoosh/cli --webp '{"quality":80}' -d public/assets/data/images/ratings/ public/assets/data/images/ratings/*.png
```

> **Note:** Squoosh CLI is no longer actively maintained but still functional for one-off conversions.

### ImageMagick

```bash
# Convert a single file
magick input.png -quality 80 output.webp

# Batch convert
for f in public/assets/data/images/ratings/*.png; do
  magick "$f" -quality 80 "${f%.png}.webp"
done
```

## Browser Support

WebP is supported by all modern browsers (Chrome 32+, Firefox 65+, Safari 14+, Edge 18+). As of 2025, global support exceeds 97%. The `<picture>` fallback to PNG ensures the rare unsupported browser still displays images correctly.
